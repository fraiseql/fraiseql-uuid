# Changelog

All notable changes to fraiseql-uuid are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [Unreleased]

## [0.1.5] - 2026-11-07

### Fixed

- `fraiseql_uuid.__version__` is the installed distribution's version. It said
  `0.1.0` since 0.1.0, whatever version was installed.

## [0.1.4] - 2026-11-05

### Changed

- fraiseql-uuid is developed and released from its own repository,
  [fraiseql/fraiseql-uuid](https://github.com/fraiseql/fraiseql-uuid), with its
  history. It was `packages/fraiseql-uuid` in fraiseql/fraiseql-seed, which is
  being retired. The package name and its API are unchanged.

The last release from fraiseql/fraiseql-seed.
